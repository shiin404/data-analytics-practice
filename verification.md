# Проверка проекта

Проверка выполнена 24 ноября 2026 года на Python 3.12.

## База и аналитика

- Два последовательных запуска setup_db.py: 20 → 20 записей.
- Добавление дня 5: 20 → 25 записей, 4 → 5 категорий; повторное добавление ничего не меняет.
- Итог: 3 139 000 тенге, 160 единиц, 25 записей.
- Четыре теста test_project.py завершились с результатом OK.
- analysis.py создал пять PNG и JSON с результатами; пропуски и совпадения без ID отсутствуют.
- Эксперимент с выбросом изменил среднее; после rollback данные совпали с исходными.
- Обнаруженное при тестировании удержание соединений SQLite исправлено явным закрытием через contextlib.closing.

## Приложение

- Streamlit AppTest: четыре показателя и три Plotly графика без исключений.
- Фильтр «Техника» и «Ноутбук»: 1 280 000 тенге, 4 единицы, 3 записи.
- Пустой выбор категорий: нулевые счётчики, сообщение, отсутствие графиков и доступная кнопка CSV.
- На отдельной БД после добавления пяти продаж и перезапуска интерфейса показатели изменились с 2 635 500 / 132 / 20 до 3 139 000 / 160 / 25; появилась категория «Спорт».
- В браузере подтверждены показатели, три отрисованные диаграммы и таблица; скриншоты сохранены в screenshots/.
- CSV проверен кодом: BOM, кириллица, число строк выбранного набора и заголовки при пустом наборе. Загрузка через браузерную автоматизацию не завершилась; её результат отдельно не подтверждён.

## Среда проверки

Для проверки установлены pandas 3.1.1, matplotlib 3.11.2, plotly 7.1.0 и streamlit 1.67.0.
Встроенная песочница блокировала локальные сокеты; AppTest и сервер запущены с разрешённым локальным доступом. На функциональность проекта это не влияет.
